SCRIPT USAGE
------------
To make weapon assembly easier I made a simple script that instantiates prefabs together into a weapon with selected or randomized parts.

Drag and drop "WeaponGenerator" prefab into your project hierarchy.
In the Inspector window of the "WeaponGenerator" you can see a "Procedural Gun Generator" script:
- Assemble On Start 	- Will assemble the weapon on start.
- Force Reassemble 	- In Play mode, hitting this boolean will reassemble the weapon with the current settings.
- Body
	- Random - Randomized body
	- Single Action - A "one shot per reload" body. Inspired by the Hebel Model 1894 Flaregun.
	- Revolver - A revolver handgun body. Inspired by the Gasser M1870 Revolver.
	- Bolt Action - A bolt action rifle body. Inspired by the Mannlicher M1895 Rifle.
	- Semi Automatic* - A semi automatic handgun body. Inspired by the Mauser C96 Handgun.
	- Automatic** - An automatic submachinegun body. Inspired by the Hellriegel M1915 Prototype.

	* For the semi automatic handgun's reload animation you should use the "AmmoFeeder" prefab.
	** For the automatic submachinegun's reload animation you should either use the "AmmoMagazine" or "AmmoMagazineDrum" prefab.
	** The automatic body has a "MagazinePosition" gameobject. Use this as parent to position the magazine prefab correctly.
- Handle
	- Broomstick - A simple, slim handle for handguns.
	- Pistol - An old-timey handle for handguns with ornate detail.
	- Stock - A rifle stock.
- Barrel
	- Short / Medium / Long - A simple gun barrel.
	- Handguard short / long - A gun barrel with handguard - best use for rifles or carbines.
	- Watercooled short / long - A large watercooled barrel - best use for machineguns, but could also work as suppressor.
- Aim
	- Simple - A simple rear sight.
	- Reflex - A circular sight with a metal centerpoint.
	- Scope - An early sniper scope prototype.

- Parts List	- A list of the prefab objects, no need to change it.

PREFABS
-------
Some prefabs were already explained above, those will include an "Explained above" with further info if necessary.

- AimFlat_Reflex	- A circular sight with a metal centerpoint.
- AimFlat_Scope		- An early sniper scope prototype.
- AimFlat_Simple	- A simple rear sight.
- AimRound_Reflex	- A circular sight with a metal centerpoint.
- AimRound_Scope	- An early sniper scope prototype.
- AimRound_Simple	- A simple rear sight.
* Flat and Round differ in the base of the mesh for better placement on different bodies.

- Ammo_Combustion 	- A combustion cartridge, i.e. should set target on fire.
- Ammo_Combustion_Casing - The empty casing of the above cartridge.
- Ammo_Explosive 	- An exploding cartridge.
- Ammo_Explosive_Casing - The empty casing of the above cartridge.
- Ammo_Piercing 	- A piercing cartridge. Has a sharp tip.
- Ammo_Piercing_Casing 	- The empty casing of the above cartridge.
- Ammo_Punch 		- A punching cartridge. Has a rounded, bulky tip.
- Ammo_Punch_Casing 	- The empty casing of the above cartridge.

- AmmoFeeder 	- A feeder mesh used for the Semi-Automatic body's reload animation.
- AmmoMagazine 		- A magazine used for the Automatic body's reload animation.
- AmmoMagazineDrum - A drum magazine used for the Automatic body's reload animation.

- Barrel_Handguard_Long		- A gun barrel with handguard - best use for rifles.
- Barrel_Handguard_Short	- A gun barrel with handguard - best use for carbines.
- Barrel_Long			- A simple gun barrel.
- Barrel_Medium			- A simple gun barrel.
- Barrel_Short			- A simple gun barrel.
- Barrel_WaterCooled_Long	- A large watercooled barrel - best use for machineguns, but could also work as suppressor.
- Barrel_WaterCooled_Short	- A large watercooled barrel - best use for machineguns, but could also work as suppressor.
- BodyAutomatic		- An automatic submachinegun body. Inspired by the Hellriegel M1915 Prototype.
- BodyBoltAction	- A bolt action rifle body. Inspired by the Mannlicher M1895 Rifle.
- BodyRevolver		- A revolver handgun body. Inspired by the Gasser M1870 Revolver.
- BodySemiAuto		- A semi automatic handgun body. Inspired by the Mauser C96 Handgun.
- BodySingleAction	- A "one shot per reload" body. Inspired by the Hebel Model 1894 Flaregun.
- Handle_Broomstick	- A simple, slim handle for handguns.
- Handle_Pistol		- An old-timey handle for handguns with ornate detail.
- Handle_Stock 		- A rifle stock.

- WeaponGenerator	- Add this prefab to your scene, and it automatically assembles a preset weapon. See above!

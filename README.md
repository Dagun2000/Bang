# Bang!

**동시 행동 심리전 대결 게임 (4인)**

턴을 기다리는 지루함과 조기 탈락 후의 무료함을 줄이기 위해, 모든 플레이어가 같은 타이밍에 행동을 선택하고 동시에 정산하는 서바이벌 대결 게임입니다. 무기는 공개, 직업은 비공개로 배정되어 블러핑과 심리전이 성립합니다.

- 개발 기간: 2024.12 ~ 2025.02
- 엔진: Unity (C#)
- 네트워크: Steamworks.NET (P2P, Steam Lobby 기반)

## 핵심 시스템

### 1. 동시 제출 동기화

정해진 서버 없이, Steam 로비의 `SetData`/`GetData`를 공유 상태 저장소처럼 사용합니다. 각 플레이어는 자신의 행동(타겟, 재장전 여부, 스킬 사용)을 `Turn_*_{내ID}` 키에 기록하고, 호스트(`GameManager`)가 `HostTurnCheckRoutine` 코루틴으로 0.3초 간격 폴링하며 전원의 `Turn_Ready` 값을 확인합니다. 전원 제출이 확인되면 호스트만 `ResolveAllTurnsCoroutine`을 실행해 턴을 정산하므로, 클라이언트 간 판정 결과 불일치가 발생하지 않습니다.

턴 정산은 네 단계로 순차 진행됩니다.

```
Skill → Reload → Fire → Result
```

각 단계마다 `lobby.SetData("Phase", ...)`로 진행 상태를 알리고, 해당 단계의 애니메이션 재생 시간만큼 `WaitForSeconds`로 대기한 뒤 다음 단계로 넘어갑니다.

### 2. 직업 시스템

`Job.cs`가 9종 직업(보안관/좀비/순교자/처형자/흡혈귀/스피드슈터/해커/의사/조커)의 이름·설명·패시브/액티브 여부를 반환하는 정적 팩토리(`Job.Create(JobType)`) 역할을 하고, `JobEffectHandler.cs`가 각 직업의 스킬 로직을 타입별 분기 메서드로 구현합니다. 데미지 계산 전(처형자 보너스), 사망 판정 시(보안관 생존/좀비 부활), 사망 후(순교자 광역 피해/흡혈귀 회복) 등 게임 진행 시점별로 메서드가 분리되어 있습니다.

직업 배정은 `SteamLobby.AssignJobsToAllPlayers`에서 Fisher-Yates 셔플로 9종 중 서로 다른 직업을 참가자 수만큼 무작위 배정합니다.

### 3. 무기 시스템

세 종류(자동권총/리볼버/중절총)가 데미지·최대 탄약·자동 여부로 구분됩니다(`Weapon` 클래스). 자동권총은 발당 탄약 2를 소모하는 대신 동시에 두 명을 타겟팅할 수 있습니다. 무기는 로비 단계에서 직접 선택하며 다른 플레이어에게 공개되지만, 직업은 비공개로 배정되어 "공개된 무기 + 숨겨진 직업"이라는 정보 비대칭 구조를 만듭니다.

### 4. 타이브레이커

생존자가 동시에 0명이 되면(2인 이상), 러시안 룰렛 방식의 타이브레이커로 전환됩니다. 참가자 수만큼 챔버를 셔플(실탄 1발)해 순서대로 클릭하며, 실탄이 나온 플레이어가 탈락합니다. 마지막 생존자가 최종 승자입니다.

### 5. 테스트 모드

실제 플레이어가 1명일 때 자동으로 활성화되어(`enableTestMode`), 가짜 플레이어 3명을 생성하고 무작위 타겟으로 행동을 자동 제출합니다(`InitializeFakePlayers`, `SubmitFakePlayerActions`). 혼자서도 전체 게임 루프를 검증할 수 있습니다.

## 캐릭터 커스터마이징

로비에서 얼굴/머리/의상 등을 선택할 수 있으며(`CharacterCustomizer`, `CharacterCustomData`), 선택 결과는 CSV 문자열로 직렬화되어 Steam 멤버 데이터로 동기화됩니다. 서드파티 캐릭터 커스터마이징 에셋을 감싸는 얇은 래퍼로 구현했습니다.
